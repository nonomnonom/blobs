## Ask a question

Write a question in the chat box and send it. Blobs searches enabled local libraries, then streams a reply using your selected model. You can keep reading as the answer appears.

For a focused question, choose specific sources before sending. An enabled library can supply material for answers; a disabled one stays saved but is left out of retrieval.

## Open a citation

Numbered references connect an answer to source passages. Tap a citation to open the passage and article inside Blobs. Read the surrounding text and attribution to understand what the source actually supports.

A citation is a way to inspect evidence, not a promise that every generated sentence is correct. A model can misunderstand a passage. Source dates also matter, particularly for travel arrangements and local guidance.

If a question falls outside your saved material, add a relevant library or document, or narrow your question. See [your library](/docs/library).

## Stop a reply

Tap **Stop** while Blobs is replying. You don’t need to wait for a long response to finish before moving on.

## Return to a conversation

Use the button at the top left to open full-screen conversation history. Select a conversation to continue it, or start a new chat for a different topic. Conversations and drafts stay on your phone.

Use the conversation’s available actions to rename, export, or delete it. Check an exported file before sharing: exports can contain your messages and source material.

## Read without leaving

Library search, citation passages, and installed articles open in the app. You can read this saved material offline. An original-source web address is attribution; opening that website separately requires a connection and uses your browser.
