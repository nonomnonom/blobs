This guide describes the intended behavior in the current source. Android
device acceptance is pending, so it is not a measured support promise.

## Downloads and storage

**A download stopped.** Reconnect and retry the same download. The current
source resumes a compatible partial download and verifies it before
installation. Keep the app open during setup.

**There isn’t enough space.** Follow the app’s free-space guidance, which accounts for installation as well as the downloaded file. Remove optional saved libraries or an unused model from their management screens, then retry. Avoid clearing all Android app storage just to retry a download: that also removes chats and settings.

**A file failed verification.** Retry from a stable connection. Don’t rename or modify a package to bypass the error. If it repeats, report the asset name and app version through [GitHub issues](https://github.com/nonomnonom/blobs/issues/new/choose).

## A model is slow or can’t load

Try a smaller supported model in **Settings → Models**, close other memory-heavy apps, and let a hot phone cool down. Available RAM, processor, prompt size, and Android’s memory pressure affect performance. Download size alone doesn’t tell you how much working memory the model needs.

Tap **Stop** if you no longer need a reply. Starting again with a shorter, more focused question can reduce work.

## I can’t find the source I expected

Check that the library is downloaded and enabled for answers. If you selected specific sources for the conversation, check that selection too. A saved library can remain on your phone while being disabled for retrieval.

Downloaded material is a snapshot, not a live web search. A topic outside the installed collection may need a different pack or your own document.

## An imported PDF has no useful text

Try selecting and copying text in a PDF reader. If the pages are images, Blobs can’t extract their contents. Export a text-based version outside Blobs, then import that file. Protected PDFs aren’t supported.

## Make text easier to read

Use Android’s system font-size and display-size settings. Blobs follows those preferences; there isn’t a separate text-size slider to manage. Appearance options in Blobs let you choose the light or dark theme or follow the system.

## Update the app

Download a newer APK from [GitHub Releases](https://github.com/nonomnonom/blobs/releases/latest). Blobs 0.4.0 is signed with a new key, so Android will not install it over 0.3.14 or older. Export the conversations you want to keep, uninstall Blobs, then install 0.4.0 fresh; later releases install over 0.4.0 normally. Android requires a matching application ID and signing key for an in-place update. Keep backups of exports you want to retain before uninstalling any app.

## Still stuck?

Create an [issue](https://github.com/nonomnonom/blobs/issues/new/choose) with your app version, phone model, Android version, steps to reproduce, and the visible error. Redact private messages, document contents, and credentials. Security concerns belong in [private reports](https://github.com/nonomnonom/blobs/security/advisories/new).
