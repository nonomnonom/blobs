A model runs on your phone to write replies. Blobs searches your enabled libraries and supplies relevant passages to that model. Your prompts and sources aren’t sent to a hosted AI service.

Minimum RAM is the list’s compatibility floor, not a guarantee of a particular speed. Android, other apps, prompt length, temperature, and available memory all affect performance. Installation needs room for the download, verification, and the installed model; follow the space guidance in the app.

## Pick a comfortable starting point

Use the model recommended during setup first. Qwen is the smallest download. The Gemma options use more storage and memory. You can change your choice later without replacing your libraries.

## Change models

Open **Settings → Models**. Download another compatible option, then select the installed model you want to use. Downloading and switching are separate actions. Remove a model you no longer need to reclaim storage; keep another working model available for chat.

Tap **Check for updates** when connected to refresh the available choices. Opening the screen doesn’t start a background download.

## Bringing a model file

**Add a model file** is available in model settings for local packages. Being a GGUF file does not by itself make a model compatible: architecture, tokenizer, prompt formatting, and memory requirements must also fit the pinned runtime. The in-app choices are the supported starting point.

## What helps it feel faster?

Use a smaller model, keep questions focused, and limit the sources you ask Blobs to search when that helps your task. You can stop a reply at any time.

Leaving the app releases model memory. Returning to chat can require loading it again; your saved conversations remain available.
