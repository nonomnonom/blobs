# Android screenshots

Ten native Blobs 0.3.12 screens, captured on Android 16/API 36 in Light appearance. These are application captures, not web mockups. No generated conversation reply is shown. Saved collections and storage values reflect the capture environment; they are not default contents or universal device recommendations.

The PNG captures were converted to lossless WebP with Sharp 0.35.5, effort 6. Dimensions and visible contents are unchanged. Refresh these files when the corresponding application screens change. Screen captions and alternative text live in `components/screen-gallery.tsx`.

Original Blobs interface artwork and branding remain subject to the root `NOTICE`. Model marks identify their respective publishers; see `android/THIRD_PARTY_NOTICES.md`.

`reader.webp` includes text from **Amed**, by Wikivoyage contributors, in the September 2026 travel snapshot.
