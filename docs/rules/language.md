# Language

Blobs is a global product. English is the required language for source code,
identifiers, comments, developer documentation, release metadata, catalog
metadata, package metadata, and new default UI copy.

Do not add Indonesian prose, identifiers, or hard-coded Indonesian UI strings
to product code or repository documentation. Internationalisation is a future
product capability: it must use an explicit locale design and translated
resources, never language-specific branches scattered through retrieval or
runtime code.

This rule does not alter quoted source evidence, titles, URLs, licences,
attribution, historical artifacts, or user-provided content. Preserve those
bytes and their language exactly so a source remains verifiable.
