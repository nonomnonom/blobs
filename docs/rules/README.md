# Blobs engineering rules

These rules apply to the Blobs Android application, native runtime, corpus,
release tooling, and evaluation tooling in this repository. They complement the
[architecture](../architecture.md), [engineering roadmap](../engineering-roadmap.md),
and workspace instructions.

1. [Architecture and ownership](architecture-and-ownership.md)
2. [Naming and layout](naming-and-layout.md)
3. [Language](language.md)
4. [Testing and evaluation](testing-and-evaluation.md)
5. [Workspace hygiene](workspace-hygiene.md)

Every change must have a clear module owner, an explainable dependency
direction, and evidence proportionate to its risk.
