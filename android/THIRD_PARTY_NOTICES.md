# Asset and dependency notices

Original Blobs artwork and its recorded provenance are maintained in ../design/brand-kit/ and bundled locally in the native app. Headspace reference screenshots and the user's mascot reference sheet are not bundled. The launcher vector represents the original Blobs icon. No Headspace brand assets are shipped.

Bundled notices are readable offline in Settings → About Blobs and under app/src/main/assets/licenses/:

| Component | Recorded license/provenance |
| --- | --- |
| Nunito and DM Sans | SIL Open Font License, separate bundled texts |
| Phosphor icons | MIT, bundled copyright/license |
| llama.cpp and ggml | MIT, upstream license from the pinned commit in third_party/llama.lock.json |
| Arm KleidiAI | Apache 2.0 and BSD 3-Clause components; upstream texts and copyright in KleidiAI.txt; pinned in third_party/kleidiai.lock.json |
| AndroidX, Kotlin, Coroutines, serialization, Okio, Guava and JSpecify | Publisher POM license entries and artifact notices in Runtime-dependencies.txt; Apache 2.0 text included |
| Android NDK runtime | Complete NOTICE supplied with pinned NDK 27.1.12297006 |
| Qwen3 fallback and Google Gemma 4 E2B/E4B QAT GGUF weights | Apache 2.0; exact publisher repository, revision and checksum in the in-app package catalog and installed package metadata |
| Wikipedia starter text | CC BY-SA 4.0; license text, per-article revision URL, contributor credit and adaptation note included |

Runtime-dependencies.txt is generated by tools/collect_notices.py from the pinned runtime lock graph and resolved local Gradle artifacts. The inventory includes platform/BOM and variant coordinates; R8 can remove unused code. The sole missing POM license entry, Guava ListenableFuture 1.0, is identified through [Guava's upstream license](https://github.com/google/guava/blob/master/LICENSE). SQLite itself is public domain; the AndroidX wrapper's notices are included.

llama.cpp and KleidiAI sources are fetched and checksum-verified during development, then statically linked into libblobs.so. KleidiAI is enabled for ARM64 with upstream feature dispatch; x86_64 uses the existing CPU path. Neither source is downloaded by the app. Model weights and library packages are separate from the APK. Preserve their license texts and attribution alongside distributed packages.

The original application code and Blobs artwork have no owner-selected public license yet. Third-party licenses do not grant rights to the complete original project. The GitHub repository is public; the app is not distributed through Google Play.

The shared host-side corpus builder and Kiwix extraction dependencies have separate [preparation notices](../corpus/THIRD_PARTY_NOTICES.md). Neither libzim nor the HTML parser is part of the APK. Library packages retain their own contributor attribution and modification notices.
